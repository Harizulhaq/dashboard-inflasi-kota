# Dashboard Keterprediksian Inflasi Kota di Indonesia

Dashboard hasil skripsi Akmal Harizulhaq (23.11.5783), Informatika Universitas AMIKOM Yogyakarta.
Semua angka dibaca dari `ringkasan_hasil.xlsx`, keluaran notebook Source_Code_Skripsi_Akmal_Final_v2.

## Isi repository
- `app.py`: kode dashboard Streamlit
- `requirements.txt`: daftar library
- `ringkasan_hasil.xlsx`: hasil penelitian

## Menjalankan di komputer sendiri
```
pip install -r requirements.txt
streamlit run app.py
```
